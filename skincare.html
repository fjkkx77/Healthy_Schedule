🧴 私人护肤档案

每日护肤流程

早 C + 防晒 · 晚间补水修护 · 两瓶水分工

⚠️ 全程铁律 · 早晚都不能违反
1裂可宁不再上脸 —— 封闭性太强，上脸容易闷出闭口，早上还会让防晒搓泥、成膜不均；脸上的锁水交给 C 乳，裂可宁留着擦手脚干裂
2涂了 VC 就要涂防晒 —— VC 本身不会让人变黑，但它挡不住紫外线；不打算涂防晒的日子，早上就跳过 VC，或者把 VC 挪到晚上用
3防晒永远是早上最后一步 —— 前面的乳液等 1–2 分钟吸收再涂，涂完再等几分钟成膜后出门，顺序反了会破坏防晒膜
4VC 要慢慢建耐受：前一周隔天早上用、半泵起步，耐受后再加到每天 1 泵
5湿敷不能天天做 —— 单次 3 分钟左右、一周不超过 2 次，敷完马上接乳液锁水；频繁湿敷反而削弱屏障
6现阶段不用 A 醇、不叠加酸类 —— 走「早 C + 防晒」的稳妥路线；以后想加 A 醇，先看页面下方的注意事项
7防晒说明上写了需要卸妆（如防水型）的，晚上先卸妆再洁面
现在是早上还是晚上？ · 选择会自动记住
🧴 产品清单
🧼
温和氨基酸洁面
早晚都用 · 流程第一步
💧
依漾 B5 精华水（500ml）
日常早晚的主力水 · 补水打底，洗完脸轻拍上脸；大容量，放心用
🫧
OPOSI B5 积雪草爽肤水
不天天用，当「灭火水」· 熬夜脸发黄、长痘泛红、晒后发热时拍或湿敷 3 分钟左右
☀️
春日来信 10% VC 精华
早上用（当天必须涂防晒）· 1 泵，避开眼周薄皮；避光存放，开封尽量 2 个月内用完，变黄就别上脸
🧴
TONDI 神经酰胺精华乳
早晚修护 · 全脸薄涂，巩固屏障、舒缓泛红
🫙
适乐肤 C 乳
晚上必用、早上按需 · 最后一步锁水，替代原来裂可宁的位置；晚上 1 泵，早上半泵
🌞
防晒霜
仅早上 · 足量涂抹，早间流程的收尾；用了 VC 的日子不能省
✋
裂可宁
已移出脸部护肤 · 留着擦手、脚的干裂
🚨 出现这些情况就调整
用 VC 后持续刺痛、泛红 → 停用 VC，只留 B5 水 + TONDI 乳 + C 乳修护，等屏障稳定再从半泵重新建耐受
冒出闭口痘、脸发闷 → 先减早上 C 乳的量（半泵或不加），夏天、偏油时早上只用 TONDI 乳；确认没把裂可宁涂到脸上
涂防晒时搓泥 → 前面的乳液减量，等 1–2 分钟吸收、摸着不黏了再涂防晒，按压上脸别来回搓
VC 精华颜色变黄 → 已经氧化、有效成分基本失效（抗坏血酸的氧化受 pH、氧气和金属离子催化，最稳定的 pH 区间是 2.5–3.0）。主要问题是白涂，不必恐慌，但没必要继续用，换新的
皮肤发黄、变敏感 → 多半是湿敷太频繁，先停湿敷，只做基础的水 + 乳
最近暗沉、发黄、长痘，而以前不护肤也挺好 → 先看作息和饮食：熬夜、不规律、少运动、奶茶甜食多，这些比多涂一瓶精华影响大，作息安排见首页时间表
🧪 以后想加 A 醇 · 现在不用，先收起来
展开看加 A 醇之前要知道的 6 件事
只在晚上用：A 醇见光容易分解，也会让皮肤对日晒更敏感
第二天必须防晒：用了 A 醇就不能「看心情涂防晒」，要么涂足防晒，要么宅家；准备暴晒（出游、海边）的前一晚停用
低浓度、隔天起步：比如一周一、三、五晚上用，耐受后再加频率；新手可选 A 醇 + A 酯复配的「双 A 醇」，相对温和
放在哪一步：洁面 → 依漾水 → A 醇 → TONDI 乳 → C 乳；刚开始刺痛可以先涂一层 TONDI 乳再上 A 醇（乳 – A 醇 – 乳）
用 A 醇的当晚不要全脸湿敷，正常轻拍水就行
持续泛红、脱皮、刺痛就停，回到不含 A 醇的流程；备孕、怀孕、哺乳期不要用
